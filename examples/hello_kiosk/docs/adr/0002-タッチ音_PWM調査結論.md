# 0002: オンボード PWM ブザーをタッチ音に使用しない

## 状態

採用

## 背景

PW-SH6 の Device Tree には `pwm-beeper` 相当の定義があるため、PWM4 とアンプ enable を
使ってタッチ音を出せる可能性を調査した。

## 決定

オンボード PWM ブザー経路によるタッチ音の実装は行わない。DTB/pinmux の追加修正も
この目的では行わない。音を必要とする場合は USB オーディオを優先する。

## 理由

- pinmux、PWM4、アンプ enable をレジスタ直叩きで再現しても実機は無音だった。
- `pwm-beeper` ドライバの正規 evdev 経路でも無音だった。
- トーン送出中に PWM4 の波形生成と GPIO enable が動作していることを実測しており、
  Linux から到達できる範囲より下流の実配線・回路が原因と判断できる。

## 影響

- `pwm-beeper` が bind していても、PW-SH6 で音が出ることを意味しない。
- Device Tree の `buzzer_pins` を有効化するだけでは解決しない。
- 電源/リセット時の本体音と Linux から制御できる PWM4 経路は同一とはみなさない。

## 再評価条件

PW-SH6 の回路図、teardown、実配線情報などによりオンボード音声経路が特定できた場合に再評価する。
