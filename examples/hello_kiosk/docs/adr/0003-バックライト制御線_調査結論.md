# 0003: バックライトの独立制御を行わない

## 状態

採用

## 背景

Device Tree には `pwm-backlight` が定義されているが、sysfs の brightness を変更しても
PW-SH6 実機の明るさは変化しなかった。PW-SH6 固有 DTS の LCD enable GPIO も含めて
実機で確認した。

## 決定

現状の KIOSK ではバックライトの独立 ON/OFF・調光を行わない。`Backlight` モジュールは
参考実装として残すが、通常動作からは使用しない。

## 理由

- `pwm-backlight` の値と PWM0 レジスタは変化するが、実画面の明るさは変わらない。
- PW-SH6 固有の `sharp,en-gpios` は LCD パネル電源/リセット系であり、個別に落とすと
  白画面になり再起動が必要になる。
- 実機で安全に操作できる独立したバックライト制御線は確認できていない。

## 影響

- 無操作時に sysfs brightness を下げても、省電力や消灯を保証できない。
- 見た目の「スリープ」やサスペンド相当動作には、別途 DRM/パネル側の対応が必要になる。

## 再評価条件

回路情報が得られる、または brain-hackers 側で PW-SH6 の DRM disable/resume 経路が
実装され、安全な消灯・復帰が確認できた場合に再評価する。
