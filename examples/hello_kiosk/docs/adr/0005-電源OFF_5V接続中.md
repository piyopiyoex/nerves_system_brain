# 0005: 5V 接続中は真の電源断を前提にしない

## 状態

採用

## 背景

PW-SH6 を USB/5V 給電したまま `/sbin/poweroff` すると、一度停止した後に自動的に再起動する。
設定可能な自動再起動関連ビットを無効にしても同じ挙動だった。

## 決定

5V 接続中の「電源を切る」は真の電源断として扱わない。現在の UI ではケーブルを外してから
poweroff する運用を基本とし、サスペンド相当の擬似 OFF は実装しない。

## 理由

- 5V 接続中は poweroff 後に BootROM まで再起動することを実機で確認した。
- `PWRUP_VBUS_CMPS`、`AUTO_RESTART`、RTC alarm 系を無効にしても再起動したため、
  i.MX28 PMU の 5V 存在時のハードウェア挙動と判断している。
- 安全なサスペンドには wakeup source と画面消灯手段が必要だが、現状はいずれも成立していない。

## 影響

- USB/5V 接続中に poweroff を繰り返すと再起動する。
- 純正 Brain の「OFF」はサスペンド相当の可能性があるが、現時点では推測であり前提にしない。

## 再評価条件

PSWITCH を wakeup source として扱えるカーネル対応と、安全な画面 disable/resume が成立した場合は、
サスペンドを使った擬似 OFF を再評価する。
