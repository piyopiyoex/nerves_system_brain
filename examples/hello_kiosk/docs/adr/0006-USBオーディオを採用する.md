# 0006: 音声経路に USB オーディオを採用する

## 状態

採用（経路の選択。USB オーディオ実機再生は未確認）

## 背景

オンボード音声は、稼働 DTB の SGTL5000 定義が実機と一致せず、実コーデックとみられる
0x1a の型番・配線も回路情報なしでは確定できない。一方、実機カーネルには USB Audio Class と
USB host のサポートが組み込まれている。

## 決定

音声が必要な場合の主経路は USB オーディオとする。オンボード codec と PWM ブザーの追跡は、
回路情報が得られるまで凍結する。

## 理由

- USB Audio Class は標準ドライバで利用でき、未同定のオンボード codec を迂回できる。
- `CONFIG_SND_USB_AUDIO=y` と USB host サポートを実機カーネルで確認している。
- USB host + セルフパワー Hub は有線 LAN で実機動作を確認済みで、同じ物理構成を利用できる。

## 影響

- 音声利用時は microUSB を host 側で使うため、同じポートの USB-NCM gadget とは排他的になる。
- USB オーディオデバイスと、必要に応じて再生用 userspace (`alsa-utils` 等) が必要になる。
- オンボード音声の解明自体を否定するものではないが、現在の優先経路にはしない。
- この ADR は音声経路の選択を記録するもので、USB オーディオの実機再生完了を意味しない。

## 再評価条件

PW-SH6 のオンボード codec と配線が確定し、USB デバイスを追加せずに安定して再生できる見通しが立った場合に再評価する。
