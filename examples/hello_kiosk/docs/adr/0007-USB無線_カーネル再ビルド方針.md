# 0007: WiFi/BLE を Brain に載せる場合はカーネル再ビルドを行う

## 状態

採用（WiFi/BLE 機能を実装する場合の方針。現行システムの必須要件ではない）

## 背景

USB host は有線 LAN で動作確認済みだが、手持ちの WiFi ドングル 2 種は現行 Linux 6.1.70
のままでは利用できず、Bluetooth stack もカーネルに含まれていない。

## 決定

PW-SH6 自身に WiFi と BLE を載せる要件が生じた場合は、brain-hackers の対応 6.1 系カーネルを
再ビルドする。UWF-1 (AR9271) 向け endpoint 検査の調整と Bluetooth/BTUSB の有効化を
同じカーネル更新で行う方針とする。

## 理由

- RTL8811CU は現行 6.1 ツリーに必要な rtw88 USB サブドライバがなく、バックポートが重い。
- UWF-1 は `ath9k_htc` まで到達するが endpoint 検査で拒否されており、カーネル側の変更が必要。
- BLE は `CONFIG_BT` / `CONFIG_BT_HCIBTUSB` 自体が無効で、userspace だけでは追加できない。

## 影響

- ADR 0001 で採用している「既存カーネルを極力そのまま流用する」範囲を広げる変更になるため、
  実施時には root の system ADR も再評価する。
- 対応する brain-hackers 6.1 ソース/commit と実機 config の再現が必要になる。
- WiFi/BLE が不要であれば、このカーネル再ビルドは実施しない。

## 再評価条件

標準カーネルで利用できる別の USB デバイスを採用できる、または BLE を別ホストから取得するなど、
カーネル変更を不要にできる場合は再評価する。
