# ドキュメント

`hello_kiosk` の設計判断と作業記録をまとめる。

- `adr/`: 実装や今後の方針に影響する決定・確定した技術的結論
- `worklog/`: 提案、調査過程、実装報告、手順、質問書、引き継ぎなどの時系列記録
- `worklog/assets/`: worklog から参照する画像などの補助ファイル

日付付き文書は作成時点の記録。後続文書で結論が更新されている場合は、`adr/` の文書を優先する。
