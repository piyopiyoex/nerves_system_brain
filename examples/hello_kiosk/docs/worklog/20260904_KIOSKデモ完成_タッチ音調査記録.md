## 2. SSH 高速化（前日の宿題を解決）

- **真因 = persistent random seed の欠如**（前日「crng の人質」説は誤り）。
  Brainux は `systemd-random-seed` が前回シードを crng に投入して即初期化していた。
- 対策: **RngSeed + rngseed ヘルパー**（RNDADDENTROPY で credit）。
  効果を実測: `crng init done` が **250秒 → 13秒**（dmesg）。
- SshDaemon を crng 非ブロッキング + 3秒リトライ化。

## 3. タッチ音（PWM ブザー）調査 — ドライバ有効化まで成功、発音は未達

### 経緯（証拠ベース）
1. DTB に **`buzzer`（pwm-beeper, disabled）と `buzzer_cold`（アンプ電源 regulator, disabled）** を発見。
2. カーネルに **pwm-beeper ドライバ組込み済み**を確認（kallsyms: `pwm_beeper` 7, `mxs_pwm` 3）。
3. **DTB パッチで buzzer/buzzer_cold を `status="okay"` 化**（USB peripheral 維持）。
   ファイル: `nerves_system_brain/sd/imx28-pwsh6-buzzer.dtb`。SD p1 の DTB を差し替え（元は `.pre-buzzer`）。
4. リセット後、**`pwm-beeper` が `/dev/input/event2` として出現**（dmesg エラーなし）。
5. evdev `EV_SND(0x12)/SND_TONE(0x02)/value=Hz` を event2 に書込み → **受理されるが発音せず**。

### 発音しない原因（証拠で特定）
- **PWM4 は enable（PWM_CTRL 0x80064000 bit4=1）だが、PWM4_ACTIVE（duty, 0x80064080）が 0** = 無音。
- アンプ電源 pin（GPIO3 pin26、DTB で **active-low**）は **DOUT=High = OFF**。
  `regulator-always-on` なのに Low(オン)になっていない。
- → **カーネル層の問題**（mxs-pwm が duty 未設定 / アンプ regulator 未駆動）に到達。

### 重要な失敗と教訓
- レジスタ直叩き（devmem で GPIO3 DOUT を書換え）で **GPIO3 の LCD 制御線を巻き込み画面が真っ白**に
  （リセットで復旧）。
- **教訓: GPIO/PWM のレジスタ直接操作は他機能（特に LCD）を巻き込む危険。やらない。**
  発音検証・修正は正攻法（カーネルの mxs-pwm / pwm-beeper / regulator 調査 + 再ビルド）で行う。

### 次にやること（カーネル再ビルド系としてまとめる）
- `drivers/pwm/pwm-mxs.c` が pwm-beeper 要求時に duty=50% を設定するか確認。
- buzzer_cold（fixed regulator, active-low, always-on）が実際にアンプ電源を Low 駆動するか確認。
- SGTL5000 MCLK 問題・有線 LAN 化と同じ「カーネル/DTB 再ビルド」系。まとめて着手が効率的。
