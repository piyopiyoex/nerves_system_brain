# 有線LAN化(USBホスト)+ NTP自動時刻 実施記録

- 日付: 2026-09-05
- プロジェクト: hello_kiosk_brain(SHARP Brain PW-SH6 / i.MX283 ARMv5 / Linux 6.1.70)
- 目的: Nerves KIOSK を USB-NCM(母艦1:1、10.42.0.2)から **USB-Ethernet による有線LAN**へ
  移行し、LAN 上のどこからでも SSH 到達 + RTC 無しでも NTP 自動時刻取得。
- 前提提案: [20260903_有線LAN化_USBホスト_提案書.md](20260903_有線LAN化_USBホスト_提案書.md)
- 結果: **成功**。eth0 = DHCP(実測 192.168.1.36)、鍵認証SSH、default route/インターネット、
  起動ごと NTP 同期まで自動。

---

## 1. 結果(サマリ)

| 項目 | 従来(USB-NCM) | 今回(有線LAN) |
|---|---|---|
| 経路 | USB gadget、母艦1:1、10.42.0.2 固定 | USB host + USB-Ethernet、LAN参加、DHCP |
| インタフェース | usb0(NCM gadget) | **eth0**(cdc_ncm/usbnet、カーネル既定名) |
| アクセス | 母艦から USB 経由のみ | LAN 上のどこからでも `ssh user@<IP>` |
| 時刻(RTC無し) | 毎回 `settime.sh` 手動 | **起動ごと NTP 自動** |
| 給電 | PC USB は放電 | セルフパワーHubで給電/充電 |

到達点は提案書 §1-§3 のとおりだが、**提案書が「要実機確認/最大リスク」としていた項目は
本作業で全て解消**した(§2 参照)。VintageNet は使わず、**busybox udhcpc + erlinit
pre-run + udhcpc hook** の軽量構成で実現。

## 2. 決定的前提: Brainux が USB host を実証

同じ PW-SH6 実機で **Brainux(Debian 13 / 同じ 6.1.70 zImage)を起動**したところ、
microUSB に挿した **ASIX AX88179 USB-Ethernet(セルフパワーHub経由)をホストモードで認識し、
DHCP で 192.168.1.36 を取得**して LAN 稼働していた(driver=cdc_ncm)。これにより:

- **microUSB の VBUS/OTG 配線問題(提案書 §2.3 の最大リスク)= 物理的に通ると確定**。
- **カーネルの USB-Ethernet ドライバ(§2.2)= Nerves と共通の zImage に =y 組込済と確定**
  (再ビルド不要)。

→ Nerves と Brainux の**唯一の USB 差分は DTB の usb0 `dr_mode` だけ**、と絞り込めた。

## 3. Nerves との差分と改造点

`dtc` で DTB を解析した結果:

| DTB | usb0(microUSB, `usb@80080000`) | 用途 |
|---|---|---|
| 素の brain-hackers(=Brainux基) | `dr_mode = "host"` | USB-Ethernet → 有線LAN |
| Nerves(従来) | `dr_mode = "peripheral"` | USB-NCM gadget → 10.42.0.2 |

usb1(`usb@80090000`)は host だが `status=disabled`(未配線)。同じ microUSB ポートなので
**host にすると USB-NCM(10.42.0.2)は失われる**(排他)。ゆえに原本SDは温存し、複製で作業。

**必要な改造は3点:**
1. **DTB**: `imx28-pwsh6.dtb` の usb0 を `peripheral` → `host`(1箇所)。ブザーmux(PWM4)は維持。
2. **rootfs**: 起動スクリプトを USB-NCM gadget から **USB-Ethernet + DHCP** に差替。
3. **rootfs**: udhcpc フックで default route 補完 + NTP 同期。

## 4. 作業手順(母艦で完結。sudo は dd/mount/cmp のみ)

前提: 原本 Nerves SD を母艦のカードリーダに挿す。**`/dev/sda` は母艦本体、対象は SD の
`/dev/sdb` のみ**(必ず `lsblk` で確認)。owner は disk 群に無く /dev/sdX 直アクセスは sudo 必須。

1. **原本をイメージ退避**(使用域=先頭3.0GiB=6291456セクタのみでよい):
   ```
   sudo dd if=/dev/sdb of=/home/owner/nerves_kiosk.img bs=1M count=3072 conv=fsync
   sudo chown owner:owner /home/owner/nerves_kiosk.img
   ```
2. **複製**: `cp nerves_kiosk.img nerves_kiosk_lan.img`
3. **FAT(boot, offset 1MiB)の DTB 差替**(mtools、sudo不要。FATにジャーナル無し):
   - `dtc` で decompile → `dr_mode = "peripheral"` を `host` に → recompile
   - `mcopy` で現行を `imx28-pwsh6.dtb.ncm-buzzer` に退避 → host版で上書き
4. **rootfs(ext4, offset 65MiB)の編集**: ★下記「落とし穴1」により **必ずカーネル
   マウント**で行う。`losetup -Pf --show` で loop 化 → `mount ${lp}p2` → ファイルを cp →
   `chown 0:0` / `chmod` → `sync` → `umount` → `losetup -d`。
5. **複写先SDへ書込**(書込先を `cmp` で必ず確認してから):
   ```
   sudo cmp -n 3221225472 /dev/sdb /home/owner/nerves_kiosk.img && echo ORIGINAL || echo OTHER
   sudo dd if=/home/owner/nerves_kiosk_lan.img of=/dev/sdb bs=1M conv=fsync ; sync
   ```

## 5. ネットワーク設定の実体(rootfs)

### 5.1 起動スクリプト差替(erlinit)
`/etc/erlinit.config` の `--pre-run-exec` を切替:
- 旧: `/usr/bin/enable_ethernet_gadget`(configfs で NCM gadget を作り `ip addr add 10.42.0.2/24`)
- 新: `/usr/bin/enable_wired_lan`(下記)

### 5.2 `/usr/bin/enable_wired_lan`(新規)
USB-Ethernet が enumerate するのを待って `udhcpc` で DHCP。**erlinit `--pre-run-exec` は
boot をブロックする**ため(落とし穴2)、立ち上げを丸ごとバックグラウンド化して即 `exit 0`。
```sh
#!/bin/sh
log=/root/wired_lan.log
echo "enable_wired_lan start ..." > "$log"
{
    # lo/sit0 以外で /device を持つ最初の IF を最大30秒待つ
    iface=; n=0
    while [ -z "$iface" ] && [ "$n" -lt 30 ]; do
        for d in /sys/class/net/*; do
            name=${d##*/}; [ "$name" = "lo" ] && continue
            [ -e "$d/device" ] || continue; iface=$name; break
        done
        [ -z "$iface" ] && { sleep 1; n=$((n+1)); }
    done
    [ -z "$iface" ] && { echo "NO ethernet iface" >>"$log"; exit 0; }
    ip link set "$iface" up; sleep 1
    udhcpc -i "$iface" -b -s /usr/share/udhcpc/default.script >>"$log" 2>&1
} </dev/null >>"$log" 2>&1 &
exit 0
```

### 5.3 `/usr/share/udhcpc/default.script.d/50-route-ntp`(新規フック)
**この busybox には `route` applet が無い**(落とし穴3)ため、stock の default.script は
DHCP の default gateway を張れない(IP は `ifconfig`/`ip` で付くが default route が落ちる)。
`ip route` で補完し、ついでに NTP 同期(RTC 無し対策)。udhcpc が bound 時に渡す
`$router`(=gateway)を使う。
```sh
#!/bin/sh
case "$1" in
  bound|renew)
    [ -n "$router" ] && ip route replace default via "${router%% *}" dev "$interface" 2>/dev/null
    ( /usr/sbin/ntpd -q -n -p "${router%% *}" -p pool.ntp.org >/root/ntp.log 2>&1 ) &
    ;;
esac
exit 0
```

### 5.4 KIOSK の IP 表示(app 側、コミット 341975c)
`display.ex` / `kiosk.ex` の IP 表示が `usb0` 決め打ちだったため eth0 で「IPなし」に
なる。**loopback 以外で IPv4 を持つ最初の IF** を拾うよう汎用化。

## 6. ハマった落とし穴(重要)

1. **SD の ext4 rootfs を `debugfs -w` で直接編集してはいけない**。debugfs はジャーナルを
   通さず書くため、`e2fsck -y`(ジャーナルreplay)や Brain のマウント時 replay で**変更が
   巻き戻る**。実際これで2回失敗(erlinit.config が原本に戻り enable_wired_lan が消えた)。
   **正: `mount`(または `losetup -Pf` → `mount`)でカーネルマウントして cp/編集 →
   clean umount**。FAT は mtools/直書きで可(ジャーナル無し)。
2. **erlinit `--pre-run-exec` は boot をブロックする**。udhcpc をフォアグラウンド実行すると
   Erlang/KIOSK が起動せず、コンソールが最後のカーネルメッセージ「platform sound:
   (deferred probe)」で止まって見える。**ネットワーク立ち上げを `{ …; } &` で
   バックグラウンド化し即 exit 0**。旧 gadget スクリプトは末尾 `ip addr add` で即 return
   だったので問題化しなかった。
3. **busybox に `route` applet が無い**(`ifconfig`/`ip` はある)。stock udhcpc
   default.script が `route add default gw` を使うため default route が張れない → §5.3 で
   `ip route` により補完。`tr`/`touch` も未収録(ログ等の些末用途で実害なし)。
4. **運用: 唯一の通信路(eth0)上で危険なライブテストをするな**。`ip route del default` +
   udhcpc 再実行を SSH 越しにやったら、eth0 の再構成で SSH が切れて udhcpc が中断し、eth0 が
   IP を失って到達不能に(電源リセットで復帰)。検証は read 主体で。

## 7. 実機テストと確認(2026-09-05)

- 起動: 有線LAN版SD + microUSB に AX88179 + セルフパワーHub + OTG。
- `enable_wired_lan` が eth0 を検出 → udhcpc → **192.168.1.36 取得**。
- フックが `default via 192.168.1.2` を追加、`ntpd` が時刻設定
  (`ntpd: setting time to 2026-09-05 08:12:56, offset +1788595965s`)。
- `ssh user@192.168.1.36`(母艦鍵で鍵認証)で exec 動作確認。KIOSK に IP 表示。
